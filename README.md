# Portafolio de Sistemas Operativos

**Institución:** Escuela Politécnica Nacional  
**Asignatura:** Sistemas Operativos-GR1  
**Integrantes:** Miguel Rayo, Italo Rodriguez

## Descripción

Este repo contiene las actividades y scripts desarrollados durante la asignatura de Sistemas Operativos. Las actividades están organizadas por semanas, con su ayuda memoria, código y resultados.

## Contenido

| Semana | Tema | Actividades |
| --- | --- | --- |
| [Semana 1](Semana1/) | Comandos y reconocimiento de hardware | Diagnóstico con PowerShell y Bash; introducción al ensamblador |
| [Semana 2](Semana2/) | Modelo de programación, memoria y representación de datos | Reporte de memoria en Windows y Linux, demos de datos y recorrido de matrices |

## Herramientas utilizadas

- Windows 11 y PowerShell
- Ubuntu Linux o WSL y Bash
- GCC y Python 3
- VMware
- Git y GitHub
- Laboratorio de Memoria y Caché del curso

## Organización

Cada carpeta semanal contiene un `README.md` que explica su contenido y cómo ejecutar los scripts. Las salidas reales se guardan en archivos `.txt`; los resultados de un simulador se identifican como simulación.

La semana 1 conserva su organización original. En la [semana 2](Semana2/README.md), los reportes se separan en `reportes/windows/` y `reportes/linux/` para que no se sobrescriban si los dos sistemas usan el mismo nombre de equipo.

## Uso de IA generativa

Para la semana 2 se utilizó ChatGPT/Codex como apoyo para organizar la documentación, explicar los comandos, preparar y depurar los scripts, y comprobar los resultados. El estado de ejecución de cada plataforma se indica en el README de esa semana.

Este portafolio se actualizará con el transcurso de las semanas.
